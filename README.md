# sail_analysis
Build tools designed to help analyze sailing data.

- `skills/sailing-coach/`: the source of the sailing-coach skill (Njord data to a coaching debrief and HTML reports). `skills/sailing-coach.skill` is the packaged version to install.
- `sept-odw-2026/`: Sept ODW 2026 data, reports and debriefs for Mojo and 969.
