# Coaching sources

Outside material the coach learns from. Each source is read once, distilled in our own words into the matching `references/playbook/*.md` file, and logged here. The playbook is what the coach reads when writing a debrief; the links are here for credit and so a source can be re-read.

Distil, don't copy: keep each point to a sentence or two, say how it shows up in our data (what `analyze.py` measures), and cite the source by link. Where sources disagree, note both and say which fits the Etchells.
